# APPF Referee Lights – Android app

Amateur Power & Physique Federation referee lights. One app, the password decides everything.

| Platform | TV / Host phone | Left | Head | Right |
|---|---|---|---|---|
| 1 | 1100 | 1101 | 1102 | 1103 |
| 2 | 2200 | 2201 | 2202 | 2203 |
| 3 | 3300 | 3301 | 3302 | 3303 |
| 4 | 4400 | 4401 | 4402 | 4403 |

## Build the APK (GitHub, free)
1. Upload this whole folder to a new GitHub repository.
2. GitHub builds the APK automatically (tab **Actions**, about 5 minutes).
3. Download **APPF-RefLights.apk** from the **Releases** section.

## Use
- Host phone (one per platform): turn on hotspot (APPF-P1 ...), open app, enter `NN00`, cast screen to TV.
- Referee phones: join that platform's hotspot, open app, enter own password.
